# Stationery Store - PHP MVC OOP

Base project for a stationery e-commerce website.

## Stack

- PHP 8+
- MySQL
- Apache / XAMPP
- PDO
- MVC
- OOP
- HTML / CSS / JavaScript
- No framework

## XAMPP

Copy the project into:

C:\xampp\htdocs\stationery-mvc-base

Start:

- Apache
- MySQL

Open:

http://localhost/stationery-mvc-base/

## Current phase

This source contains:

- MVC base structure
- OOP core classes
- PDO database connection class
- Autoloader
- Router
- Controllers
- Models
- Views
- Basic CSS/JS
- Initial routes/pages

Database queries and business features are intentionally not implemented yet.
